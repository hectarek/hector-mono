# Security

This is a personal monorepo. The apps it deploys are listed in the [README](README.md). The recipes app holds other people's accounts and data, so reports about it matter most.

## Reporting a vulnerability

Report it privately through GitHub: on the repository's main page, open the **Security and quality** tab and click **Report a vulnerability**. Please don't open a public issue or pull request about it.

Say what's affected (the app and its URL, or the file), how to reproduce it, and what someone could do with it. It's a one-person project, so there's no fixed response time, but reports are answered as soon as possible.

## Scope

The code on `main` and the apps deployed from it. The services the apps run on (Vercel, Neon, Ably, the Vercel AI Gateway) have their own disclosure programs.
